# Общая память исследования

`exploration_base` хранит исследованные клетки карты вместе с прохождением. Мод не рисует карту, не определяет видимость через стены и не создаёт камеру. Представления 2D и 3D используют одну память, сохраняя свои правила координат и видимости.

## Для автора игры

Подключайте редактор нужного представления карты: он добавляет зависимость автоматически. Карта, начально открытые области и отметки задаются в его формах. Общая база не требует ручного JSON и не имеет отдельного авторского окна. Видимая сейчас область — временная; исследованная — сохраняется. Новая игра очищает память.

## Контракт адаптера

`ExplorationMemory.Open(id, width, height, initial)` возвращает один актуальный `ExplorationMap`. Используйте собственное пространство имён: например, `my_game/town_map`. Индекс — `y * width + x`; `initial` — список изначально открытых индексов. Он применяется только при первом создании записи. Повторное открытие не открывает области заново.

`Reveal(indices)` добавляет постоянное знание. `SetVisible(indices)` заменяет текущее множество видимых клеток и одновременно исследует их. `ClearVisibility()` убирает временную видимость. Чтение: `IsExplored(x,y)`, `IsVisible(x,y)`. `Revision` меняется только при фактическом изменении данных: вращение камеры или повторная передача того же множества не требуют перерисовывать туман.

После загрузки или новой игры `IsCurrent` старого дескриптора становится false. Повторно вызовите Open; старые операции чтения/записи откажут. Ширина/высота той же записи не могут измениться: выбирайте новый id, если меняется интерпретация клеток. Адаптер может включать в id подпись своего преобразования координат.

## Сохранение и границы

Штатный `IModSaveable` пишет версию 1 в полку `Exploration`. Сохраняются dimensions и битовая маска explored; текущая видимость и Revision не сохраняются. `Snapshot()` возвращает независимый DTO, `Restore()` сначала полностью проверяет и копирует данные, затем заменяет поколение. Неверные данные не меняют текущую память. Отсутствующая полка означает пустое поколение.

До 256 карт; каждая сторона 1–2048, всего не больше 1 048 576 клеток на карту. Переданное обновление целиком проверяется до изменения битов. Обращения выполняются в главном потоке. База не хранит запомненные объекты, двери, изображения или состояние стриминга — это данные владельцев представления.

Адресный набор `exploration_units` проверяет границы, независимость карт/снимков, начальные области, смену видимости, атомарные отказы, invalidation и полный JSON roundtrip обычной полки сохранения.
